# ZarjTest 🧪

**Экспериментальный проект** для изучения Fabric API и тестирования игровых механик.

> ⚠️ Это learning-проект, не для production-использования. Здесь я экспериментирую с идеями, которые потом могут перекочевать в ZarjLib или другие моды.
## Реализованные механики

### ⚔️ MMO-система улучшения экипировки
Кастомная система заточки, вдохновлённая MMO:

**Тиры точек улучшения:**
- Обычные (+1, +2, +3...)
- Редкие (увеличенный бонус)
- Эпические (специальные эффекты)

**Система рун:**
- Руны защиты от поломки предмета
- Руны сохранения уровня заточки при провале
- Разные редкости рун с разным процентом защиты

**Техническая реализация:**
- Кастомные GUI для модификации
- NBT-данные для хранения уровня заточки
- Визуальные индикаторы уровня (glow-эффекты)
- Серверная валидация операций

### ⭐ Звёздная система (Blood And Soul style) — WIP
Система встраиваемых звёзд в экипировку:

**Предметы системы:**
- `star_opener` — даёт возможность встраивать звезды в броню, вместе с тем задавая максимальное количество "дырок" под звёзды 
- `star_roller` — выковывает звезду (случайная редкость)
- `star_slot_extender` — "дырявит" броню, в рамках заданного star_opener максимума для предмета.

**Механика:**
1. Используй `star_opener` на броне → создаётся максимальное количество слотов
2. Используй `star_slot_extender` на броне → создаётся пустой слот в пределах максимального количества
3. Используй `star_roller` → выковывается звезда (white/green/blue/purple/gold)
   
**GUI:**
- Динамические слоты, меняющие цвет в зависимости от предмета:
  - 🟢 Зелёный — Opener/броня
  - 🔵 Синий — Roller
  - 🔴 Красный — неподходящий предмет
    
**Статус:** Реализованы предметы и базовый GUI, механика ролла не завершена.

## Техническая реализация

### Архитектура
- **Клиент-серверная логика** — вся логика на сервере
- **Кастомные ScreenHandler** — динамические GUI
- **IconSlot** — слоты с динамическими текстурами
- **NBT-данные** — хранение звёзд и уровней заточки

### Пример кода (StarOpenScreenHandler)
```java
this.addSlot(new IconSlot(inventory, 0, 30, 32, "textures/gui/slot3.png", 20){
    @Override
    public void setStack(ItemStack stack) {
        super.setStack(stack);
        if(stack.isOf(StarsItems.STAR_OPENER)){
            this.changeTexture(GREEN_SLOT);
        }else if(stack.isOf(StarsItems.STAR_ROLLER)){
            this.changeTexture(BLUE_SLOT);
        }else{
            this.changeTexture(RED_SLOT);
        }
    }
});
